# Linguagem Simples

{% endhint %}

A ferramenta **Linguagem Simples** converte textos jurídicos para uma redação acessível, que pode ser compreendida por qualquer pessoa, em conformidade com a legislação sobre Linguagem Simples. É útil, por exemplo, para:

* Comunicar o teor de decisões às partes e aos advogados em linguagem clara;
* Preparar material de atendimento e orientação ao cidadão;
* Descomplicar termos técnicos em documentos internos.

## Como Utilizar

1. Acesse a ferramenta pelo cartão "**Linguagem Simples**" na página inicial (ou pelo item de menu correspondente).
2. Cole o texto a ser convertido no editor. Também é possível **carregar um PDF** (até 10MB), selecionando-o ou arrastando-o para a área do editor.
3. Opcionalmente, use a linha "Prompt" para escolher uma variação do prompt oficial ou personalizar a instrução no campo "**Personalização do Prompt**".
4. Clique em "**Simplificar**".
5. O texto convertido é exibido abaixo, em modo editável ("Texto Editado"), permitindo ajustes finais antes de copiar o resultado.

Se você ainda não configurou uma chave de API e um modelo de IA, a Apoia preparará o prompt completo (com o texto) e o copiará para a área de transferência, para que você use na ferramenta de IA de sua preferência.

{% hint style="info" %}
O resultado da conversão deve ser revisado pelo usuário: a IA pode simplificar o sentido de passagens sensíveis, e a conferência do conteúdo é responsabilidade do autor do texto.
{% endhint %}
