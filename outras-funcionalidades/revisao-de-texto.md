# Revisão de Texto

A Apoia possui uma ferramenta específica para revisão de texto, acessível por um link no menu. O que ela faz é pegar um texto inserido em um editor e revisá-lo. A funcionalidade "Revisão de Texto" permite o refinamento de redações, mantendo o conteúdo original, mas tornando o texto mais claro, objetivo e de fácil compreensão. O prompt gera um novo texto que é então comparado ao texto original.

Acima do editor, a linha "Prompt" permite selecionar uma **variação do prompt de revisão** (a opção "Padrão" usa o prompt oficial) e até personalizar a instrução no campo "**Personalização do Prompt**" — útil para orientar o estilo da revisão (ex.: "preserve as citações em latim").

Recursos:

* Refinamento: reescreve o texto para maior clareza e objetividade.
* Comparação com texto original: destaca as alterações (inclusões, exclusões, substituições).
* Versão compacta: mostra apenas as substituições/alterações.
* Entrada por PDF: além de colar o texto, é possível carregar um PDF (até 10MB) arrastando-o para o editor.

Como utilizar:

1. Acessar a ferramenta (menu "**Revisão de Texto**").
2. **Copiar/colar** o texto a ser revisado no editor (ou carregar o PDF).
3. Clicar em "**revisar**".
4. O sistema processa o texto e apresenta a comparação.
5. Escolher o modo de visualização: diferença completa, diferença compacta, texto original ou texto refinado (editável).

É possível copiar o texto refinado diretamente da tela. Ao editar o texto de entrada ou a configuração do prompt, o resultado é ocultado até nova revisão.
